Anvilope
========

A heavy-handed approach to email

Don't Call It a Spam Filter
---------------------------

Anvilope is an email classification daemon. It will sit around and read incoming
emails using a self-hosted LLM, making a determination about each one based on
customizable prompts.

This project is pre-alpha and lacks basic functionality, but take a look if you
are curious! I'm currently working on dogfooding it with my own accounts.
